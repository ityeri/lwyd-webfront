# lwyd-webfront

Frontend for [lwyd](https://github.com/ityeri/lwyd_back) — a lightweight YouTube downloader.

React 19 + Vite + Tailwind CSS 4. Black theme with the lwyd palette.

## Dev

```bash
npm install
npm run dev        # backend expected at localhost:8000, /api is proxied
```

## Build

```bash
npm run build
```
